# Severity Matrix

| Severity     | Example                               | Response Time  |
| ------------ | ------------------------------------- | -------------- |
| **Critical** | Ransomware affecting multiple systems | Immediate      |
| **High**     | Compromised administrator account     | Immediate      |
| **Medium**   | Phishing incident affecting one user  | Same day       |
| **Low**      | Minor security policy violation       | Normal process |

# Ransomware / Account-Compromise Playbook

## For ransomware
1. Detect
   ↓
2. Report the incident
   ↓
3. Isolate affected systems
   ↓
4. Identify the scope
   ↓
5. Preserve evidence
   ↓
6. Eradicate the malware
   ↓
7. Recover from clean backups
   ↓
8. Monitor systems
   ↓
9. Document the incident
   ↓
10. Conduct lessons learned

# RACI Chart
this shows who is responsible for each incident-response activity.

RACI means:

R — Responsible: Person doing the work
A — Accountable: Person ultimately responsible for the result
C — Consulted: Person whose advice is needed
I — Informed: Person who needs to be kept updated

| Incident Activity          | IT/Security | IT Manager | Management | HR | Legal |
| -------------------------- | ----------- | ---------- | ---------- | -- | ----- |
| Detect incident            | R           | A          | I          | I  | I     |
| Investigate                | R           | A          | I          | C  | C     |
| Contain incident           | R           | A          | I          | I  | C     |
| Notify management          | R           | A          | I          | I  | C     |
| Recover systems            | R           | A          | I          | I  | C     |
| Employee investigation     | C           | A          | I          | R  | C     |
| Legal/regulatory reporting | C           | A          | I          | C  | R     |
| Lessons learned            | R           | A          | I          | C  | C     |
