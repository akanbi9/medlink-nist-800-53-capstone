## Evidence and Assumptions

All screenshots, logs, records, diagrams, policies, questionnaires, risk records, and assessment evidence created for this project are **synthetic or simulated** unless explicitly identified otherwise.

The following are project assumptions:

* Proposed system owners are assigned for assessment purposes.
* Asset IDs are created specifically for this capstone.
* Risk scores are based on the project's 1–5 likelihood × 1–5 impact methodology.
* Target dates in the POA&M are proposed remediation dates.
* Architecture and data flows represent a reasonable interpretation of the supplied MedLink scenario.
* No production system was scanned, tested, accessed, or modified as part of this student assessment.

## Version and Consultation Note

NIST publications and supplemental control resources may receive updates. This project records the NIST publication version/release and the date consulted so that the assessment can be traced to the reference material used during the project.
