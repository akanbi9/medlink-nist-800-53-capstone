# MedLink Services Ltd. — System Boundary

## 1. Overview

This document defines the system boundary for the SecureCore 53 cybersecurity and privacy assessment of MedLink Services Ltd.

The assessment uses NIST SP 800-53 as a control catalog to evaluate security and privacy controls within the simulated MedLink environment.

The environment consists of approximately 65 employees, 50 Windows laptops, 8 desktop computers, Microsoft 365 cloud services, a cloud-hosted customer portal, an internal HR and payroll application, an on-premises file server, network equipment, remote/hybrid workers, third-party vendors, physical security systems, and local/cloud backups.

---

## 5. Out-of-Scope Items

The following are outside the scope of this student assessment:

- Personal devices not used for MedLink business
- Personal accounts and personal cloud storage
- Systems belonging entirely to third parties and not managed or accessed by MedLink
- Real customer data
- Real employee personal information
- Real passwords, API keys or authentication tokens
- Real internal IP addresses or confidential network information
- Security testing of systems without explicit authorization
- Production penetration testing or vulnerability exploitation

These exclusions are intended to keep the assessment within the simulated educational environment.

---

## 6. Assumptions

The following are assumptions made for this student project and are not confirmed facts:

- Microsoft 365 is used as the organization's primary cloud productivity platform.
- A cloud identity service is used to authenticate users to Microsoft 365 and other supported services.
- The customer portal is hosted by a cloud provider.
- The organization uses a firewall to protect the internal network.
- Endpoint security software is installed on company-managed Windows devices.
- Cloud and local backups are available for critical business information.
- Third-party IT support has authorized access when required.
- Security logs are generated by cloud, endpoint, network and application systems.

---

## 7. System Boundary Summary

The system boundary includes the people, devices, applications, networks, cloud services, data repositories, vendors and physical locations that support MedLink's business operations and security.

The assessment focuses on whether appropriate NIST SP 800-53 security and privacy controls are implemented, partially implemented, or not implemented within this boundary.
